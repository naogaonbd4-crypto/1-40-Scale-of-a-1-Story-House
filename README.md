# 1-40-Scale-of-a-1-Story-House
This is a life size house, shrunk down to 1:40 scale to be able to be printable. It features 1 dining room, 1 kitchen, 1 living room, 2 bedrooms, 2 bathrooms, 1 laundry/pantry room, 1 master suite, 2 non-bedroom closets, and 1 walk-in closet. This was created for fun, could be inspiration for others to make something similar. A roof is not included if one would like to decorate the rooms with furniture, lighting, etc.
